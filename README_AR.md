# AI Video Studio — دليل التشغيل

هذا مشروع MVP يعمل محليًا ويحوّل وصف المستخدم وملفاته إلى خطة فيديو، يعرضها داخل Remotion Player، ثم يصدر MP4.

## المتطلبات

1. Node.js 20 LTS أو أحدث.
2. npm 10 أو أحدث.
3. مساحة فارغة؛ التصدير يستهلك موارد الجهاز.
4. اتصال إنترنت أول مرة لتثبيت الحزم وتنزيل Chromium الخاص بـ Remotion.
5. مفتاح OpenAI اختياري. التطبيق يعمل بدونه بمخطط محلي.

## التشغيل على Windows أو macOS أو Linux

افتح Terminal داخل مجلد المشروع ثم:

    npm install

انسخ ملف البيئة:

Windows PowerShell:

    Copy-Item .env.example .env.local

macOS / Linux:

    cp .env.example .env.local

إذا أردت الذكاء الاصطناعي، افتح `.env.local` وأضف المفتاح. ثم:

    npm run dev

افتح:

    http://localhost:3000

## الاستخدام

1. اكتب وصف الفيديو.
2. اختر اللغة والمدة.
3. ارفع الصور والفيديوهات والصوت والشعار.
4. اضغط «إنشاء خطة الفيديو».
5. راجع المعاينة وعدّل نصوص المشاهد من اليمين.
6. اضغط «تصدير MP4» وانتظر. سيُفتح الفيديو بعد اكتماله.
7. الملفات الناتجة موجودة في `public/renders`.

## ملاحظات مهمة

- الحد البرمجي الحالي للملف الواحد 250MB.
- التصدير متزامن في الـMVP؛ لا تغلق صفحة التشغيل أثناءه.
- المواد المرفوعة تحفظ في `public/uploads`.
- لا تنشر النسخة الحالية للعامة قبل إضافة تسجيل دخول، تخزين S3، Queue، وحدود استخدام.
- لا تستخدم ملفات لا تملك حقوق استخدامها.

## اختبار الأنواع

    npm run typecheck

## بناء نسخة Production

    npm run build
    npm start

## إذا فشل التصدير

- شغّل Terminal بصلاحية عادية وليس داخل مجلد محمي.
- تأكد أن مساحة القرص كافية.
- احذف `.next` ثم أعد `npm run dev`.
- جرّب فيديو 15 ثانية أولًا.
- راجع رسالة الخطأ في Terminal.
