# استوديو الموشن جرافيك بالذكاء الاصطناعي (Motion AI Studio)

منصة متكاملة لتوليد فيديوهات الموشن جرافيك السينمائية العمودية (9:16 بدقة 1080×1920) بالذكاء الاصطناعي، بمستوى احترافي منافس لبرامج مثل After Effects، مع محرك ريندر سحابي حقيقي ومزامنة صوتية كاملة.

---

## 🚀 المميزات الرئيسية

1. **محرك موشن جرافيك كودي متطور (Deterministic Motion Engine)**:
   - مبني على HTML5 Canvas و GSAP و DotLottie مع تحكم زمني قطعي إطاراً بإطار (`renderAtTime(t)`).
   - تصميم عمودي 9:16 (1080×1920) مخصص لمنصات تيك توك، ريلز، وشورتس.

2. **أنماط الرسم والهوية البصرية (Visual Styles)**:
   - كتالوج أنماط بصرية متكامل (فلات صلب، نيومورفيزم، سايبر بانك، طين ثلاثي الأبعاد 3D Clay، مينيماليزم فاخر، وVintage).
   - معاينة حية لعينات الأنماط والألوان قبل وأثناء التوليد.

3. **مكتبة الحركات الفيزيائية (Physics Motion Library)**:
   - كتالوج حركات مرجعية ديناميكية (النوابض السائلة، الجاذبية والارتداد، المسارات المدارية، الانفجار الجزيئي، والموجات الصوتية).
   - تدمج تلقائياً في سياق الذكاء الاصطناعي لإنشاء حركات فيزيائية دقيقة.

4. **نظام المسار الصوتي والمزامنة (Audio Engine)**:
   - إمكانية رفع الملفات الصوتية بصيغ متعددة (`MP3`, `WAV`, `M4A`, `AAC`).
   - دعم مباشر للتعليقات الصوتية (Voiceovers) مع مزامنة لحظية في المشغل (Play, Pause, Scrubbing, Volume, Mute).
   - دمج تلقائي للصوت مع الفيديو عند الريندر.

5. **محرك الريندر والتصدير السينمائي (Full HD MP4 Export)**:
   - ريندر خادمي حقيقي إطاراً بإطار عبر Puppeteer Core بدون الحاجة لمشاركة الشاشة.
   - تشفير عالي الجودة عبر FFmpeg مدمج بترميز H.264 للفيديو و AAC 192kbps للصوت.

---

## 🛠️ متطلبات التشغيل

* **Node.js**: الإصدار 20 LTS أو أحدث.
* **Google Chrome**: متصفح كروم مثبت على النظام (لاستخدامه في محرك ريندر Puppeteer).
* **OpenRouter API Key** (اختياري / موصى به): لتوليد نصوص وأكواد المشاهد عبر نماذج الذكاء الاصطناعي (Claude 3.7 Sonnet / GPT-4o).

## ⚙️ التثبيت والتشغيل المحلي

1. **تثبيت الحزم البرمجية**:
```bash
npm install
```

2. **إعداد ملف المتغيرات**:
انسخ ملف الإعدادات وضع مفتاح OpenRouter الخاص بك:
```bash
cp .env.example .env.local
```

3. **تشغيل خادم التطوير**:
```bash
npm run dev
```
افتح المتصفح على الرابط:
```
http://localhost:3000
```

## 🎬 كيفية الاستخدام

1. **توليد الفيديو**:
   - اضغط على زر **"توليد بالذكاء الاصطناعي"**.
   - اختر نمط الرسم المفضل وتصفح عينات الأنماط.
   - اكتب وصف الفيديو (البرومبت) أو السيناريو، ثم اضغط **"بدء التوليد"**.

2. **المعاينة والتحكم**:
   - راجع الفيديو في المشغل السينمائي.
   - يمكنك سحب التايم لاين، إيقاف/تشغيل، ومراجعة كود المشاهد من زر **"محرر الكود"**.

3. **إضافة الصوت**:
   - اضغط على **"إضافة مقطع صوتي"** من المشغل أو من نافذة التصدير.
   - ارفع ملفك الصوتي أو اختر أحد التعليقات الصوتية الجاهزة.

4. **التصدير**:
   - اضغط على **"تصدير فيديو (MP4)"**.
   - اختر معدل الإطارات (30 FPS أو 60 FPS) وتأكد من تفعيل تضمين الصوت.
   - اضغط **"بدء ريندر وتصدير MP4"** وسيتم تحميل الفيديو النهائي بجودة 1080×1920 مباشرة فور اكتماله.
